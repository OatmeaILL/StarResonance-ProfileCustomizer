# StarResonance-ProfileCustomizer

<img src="./xmp.png" width="50%">

星痕共鸣（Star Resonance）名片/头像自定义修改工具

## 功能

- 自动检索游戏数据包中的名片和头像资源
- 图片裁剪编辑器（选框拖拽、亮度、对比度、饱和度、色温调节，图片平移）
- 一键替换名片和头像
- 交互式更换流程（自动调整游戏窗口分辨率）
- 备份还原机制（退出自动还原）
- 支持快速查找和完整查找两种模式
- 支持多服务器自动检测（国服/台服/港澳服/日服/国际服）
- 手动捕获游戏窗口（兼容非国服进程名）

## 使用方法

1. 下载 [Releases](../../releases) 中的最新版本
2. 双击运行 `StarResonance-ProfileCustomizer.exe `  &#x20;
3. 首次启动需同意用户协议，随后自动弹出教程
4. 按照教程操作即可

### 操作流程

1. **选择目录** — 选择星痕共鸣游戏安装目录
2. **查找资源** — 点击「扫描数据包」→「开始查找」，程序自动搜索名片/头像资源
3. **编辑图片** — 切换到「编辑图片」，选择图片 → 裁剪 → 确认 → 下一步
4. **更换操作** — 切换到「更换操作」，启动游戏 → 按步骤操作

## 常见问题

<details>
<summary>点击展开</summary>

**Q. 为什么图片能选择的位置那么小？**
A. 因为要适配星痕共鸣的名片大小。请你选一张基础分辨率没那么大的图片进行替换。

**Q. 为什么查找的进度条这么慢？**
A. 使用的是适用性很高的自搜索方法寻找替换的文件。优点是游戏更新也不影响使用、国际服、港澳台服也适配。缺点是依赖CPU、内存、磁盘性能。

**Q. 为什么替换时窗口分辨率没有改变？**
A. 请在开始前先手动将全屏的游戏窗口改为窗口化。或尝试以管理员权限启动本程序。

**Q. 为什么进度条卡45%？**
A. 请不要替换文件之后再启动游戏/切换场景。请先进入协会，再进行文件的替换。

**Q. 游戏出问题了！闪退/游戏内有诡异现象（如建模消失等）**
A. 可能是替换后还原功能出问题了，请在WEGAME手动点击修复游戏尝试修复。

**Q. 为什么替换出来的名片拍出来是灰色的？**
A. 未在向上拖动完橙色取相框后的下一步再次上下拖动一下取相框，请认真看提示。

**Q. 国服之外的比如国际服、港澳台服可以使用吗？**
A. 可以。程序已支持台服(StarTW\.exe)、港澳服(StarHK.exe)、日服(StarJP.exe/BPSRJP.exe)、国际服(BPSR.exe)等进程名的自动检测。如果仍未检测到游戏，可点击「手动捕获游戏窗口」按钮手动选择游戏窗口；若仍无效，请尝试以管理员权限运行本程序。

## Debug 模式

如需排查问题，可开启 debug 日志：

1. 打开程序同目录下的 `config.json`
2. 添加或修改 `"debug": true`
3. 重新启动程序，日志文件将自动生成在 `logs/` 目录下

```json
{
  "debug": true
}
```

排查完毕后建议将 `"debug"` 改回 `false` 或删除该字段。

## 提交 Issue

遇到问题时，请开启 Debug 模式复现，然后在 [Issues](../../issues) 页面提交，并附上 `logs/` 目录下时间日期最近的日志文件，以便快速定位问题。
